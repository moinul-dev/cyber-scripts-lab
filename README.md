# 🛡️ Cyber Security & Automation Scripts Lab

A curated workspace of lightweight Python and Bash tools written to test network concepts, perform basic port reconnaissance, and automate system maintenance tasks.

---

### 📂 Repository Structure

- 📡 `port_scanner.py` — Multi-threaded basic TCP port scanner built with socket.
- 🐧 `system_hardening.sh` — Bash script for auditing Linux system updates and basic firewalls.
- 🔍 `hash_verifier.py` — File integrity checker using SHA-256 and MD5 hashing.

---

### 🚀 Getting Started

```bash
# Clone the lab
git clone [https://github.com/moinul-dev/cyber-scripts-lab.git](https://github.com/moinul-dev/cyber-scripts-lab.git)
cd cyber-scripts-lab

# Run the port scanner demo
python3 port_scanner.py
